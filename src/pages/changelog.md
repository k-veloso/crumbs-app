# Changelog

New features, improvements, and fixes in Crumbs.

## v1.0.0 · November 8, 2026

First release.

Meet Crumbs: a Chrome extension that helps you find your place on long pages, in ChatGPT conversations, and in standalone Markdown and JSON documents.

### Page outlines

- Jump between headings with a searchable outline that follows the section you’re reading.
- Filter by heading level and collapse groups to focus on what matters.
- Pin the outline, dock it on either side, or let it expand on hover.
- Use Jump to Top and Jump to Bottom to move quickly to either end of the page.
- Preview sections by holding Shift while hovering over headings, and copy links to supported sections.

### ChatGPT conversations

- Navigate questions, answers, and headings inside answers.
- Search available conversation entries and filter by content type.
- Follow the conversation as answers stream, with optional question times.

### Markdown reader

- Read standalone Markdown in a formatted view, with heading navigation and a Raw view for the source.
- View tables, task lists, code blocks, diagrams, and math.
- Open local Markdown files after enabling file access.

### JSON reader

- Explore standalone JSON with syntax coloring and collapsible objects and arrays.
- Search keys, values, and paths, including fields inside collapsed branches.
- Copy values, properties, and paths, or switch to Raw to see the original response text.
- Open local JSON files after enabling file access.

### Make it yours

- Choose Glazed or Plain outline styles and one of six accent colors.
- Set Markdown and JSON readers to Light, Dark, or System appearance.
- Customize keyboard shortcuts and quick buttons.
- Choose where outlines appear: all sites, specific sites, or everywhere except your listed sites.
