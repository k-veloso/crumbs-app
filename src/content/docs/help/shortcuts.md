---
title: Keyboard Shortcuts
description: Use and customize Crumbs keyboard shortcuts and hover preview.
---

Open **General → Shortcuts** in the Crumbs popup to enable, disable, customize, or reset in-page shortcuts.

## Default shortcuts

- **Pin or unpin:** <kbd>Option/Alt</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd>
- **Search the outline:** <kbd>Option/Alt</kbd> + <kbd>Shift</kbd> + <kbd>V</kbd>

Search opens the outline and focuses heading search even when the outline is collapsed. Pin/unpin controls whether the outline stays expanded; it does not replace **Show/Hide** in the popup.

The former Command/Ctrl + K search default has changed. Check the shortcut shown in your popup if you previously customized it. Hover over or focus Search or Pin/Unpin to see the current shortcut beneath its tooltip label. Disabled shortcuts do not show a hint.

## Customize a shortcut

Choose **Edit** beside an action, record the new combination, and save it. Use Ctrl, Alt/Option, or Command with a letter or number and up to two modifiers. Each action needs a unique combination. Use Reset to return to the current default.

Browser and operating-system shortcuts may take priority. Crumbs ignores its in-page shortcuts while you are typing or composing text. Changes are stored locally and apply across open tabs.

## Hover preview

**Hover preview** appears below Search in the same settings section and is enabled by default. Hold <kbd>Shift</kbd> and pause over an outline heading to preview that section. Crumbs scrolls instantly after a short delay without highlighting the heading or changing the URL, and keeps the outline list in place. Release the key to stop previewing.

Choose **Edit** to select Shift, Alt/Option, Control/Ctrl, or Command on Mac. Use only that modifier, without additional keys. You can disable the feature or reset the key to Shift. Preview does not interrupt typing, and Caps Lock is not a supported preview key.

## Opening the settings popup

Crumbs suggests <kbd>Option/Alt</kbd> + <kbd>Shift</kbd> + <kbd>X</kbd> for opening its settings popup. Chrome manages this assignment separately and may leave it unassigned if the combination conflicts with another shortcut.

To change or remove it:

1. Select **Set in Chrome shortcuts** from Crumbs.
2. Find Crumbs on Chrome's extension-shortcuts page.
3. Edit **Activate the extension**.

The Settings tooltip and the popup's shortcut display reflect Chrome's actual assignment. If none is assigned, open Crumbs from the browser toolbar.
