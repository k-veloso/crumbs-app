# Keyboard shortcuts

Open **General → Shortcuts** in the Crumbs popup to enable, disable, customize, or reset in-page shortcuts.

Default shortcuts:

- **Pin or unpin:** Option/Alt + Shift + C
- **Search the outline:** Command + K on macOS or Ctrl + K elsewhere

Shortcuts can use Ctrl, Alt/Option, or Command with a letter or number and up to two modifiers. Each action needs a unique combination. Browser and operating-system shortcuts may take priority.

Crumbs ignores its shortcuts while you are typing or composing text. Changes are stored locally and apply across open tabs.

## Opening the settings popup

Chrome manages the toolbar-action shortcut separately:

1. Select **Set in Chrome shortcuts** from Crumbs.
2. Find Crumbs on Chrome's extension-shortcuts page.
3. Assign a shortcut to **Activate the extension**.

No popup shortcut is assigned by default.
